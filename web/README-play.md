# SurvivalGame 本地试玩

2D 生存挑战：躲开追踪的敌人，存活 60 秒。Unity WebGL 构建，H5 页面承载并保存最高分。

## 运行

**不要双击 `index.html`**：WebGL 在 `file://` 下无法加载，必须用 HTTP 服务打开。

- Windows：双击 `start-local.bat`（优先用 Python 3，没有则用 Node）。
- macOS / Linux：`sh start-local.sh`
- 或者手动：在本目录执行 `python -m http.server 8000`，然后打开 <http://localhost:8000>。

首次加载需要下载约 9MB 的 Unity 产物；页面有进度条，加载完成后「开始游戏」才可用。

## 操作

- 桌面：`WASD` / 方向键移动；`Esc` 或 `P` 暂停/继续；也可以按住鼠标拖动。
- 手机：在游戏画面上拖动移动；点画面内「暂停」；暂停后点「继续」，3 秒倒计时结束开始。
- 失焦 / 切到别的 App 会自动暂停，切回**保持暂停**，需要自己点「继续」或按 `P`。

## 规则

- 存活 60 秒获胜；生命归零失败。
- 结算显示本次得分、历史最高分、昵称、存活秒数；最高分存在浏览器 localStorage。
- 分数 = 存活分 + 胜利奖励（目前没有击杀手段）。

## 已知限制

- 无音效；敌人/玩家是占位图形（圆点 + 网格）。
- iOS Safari 对网页全屏支持有限；竖屏会提示「横屏体验更佳」。
- 首次加载体积约 9MB，网络慢时需要等待进度条走完。
