## 2. 关键实现决策

- **昵称只在 H5**：`StartGame` 的 JSON 里带昵称，Unity 只保存并原样放进 `onGameOver`，不进入任何 TMP 文本。
- **昵称输入容错**：空白 → 「玩家」；按码点截断 16（emoji 不被截成半个）；Unity 侧再兜底截断 64。
- **状态由 Unity 广播驱动**：H5 不轮询；`onReady` 前开始按钮 disabled，点击后立即禁用，3 秒无响应兜底恢复。
- **最高分**：`survival.bestScore`，仅 `score > best` 更新；相等不算新纪录。
- **可见性暂停**：桥接层记 `_pausedByVisibility`；手动暂停不设标记，因此切回标签页不会自动继续。
- **结算幂等**：Unity `_reported` + H5 `gameOverHandled` 双保险；每局只显示一次结果。
- **缓存**：Unity 产物文件名固定，`/unity/Build/*` 与 `build-info.json` no-cache；H5 js/css 带 `?v=` 且 no-cache。

### 9.2 门禁发现并修复的缺陷

- **现象**：真实浏览器里点「开始游戏」后，Unity 已进入 Playing（HUD 动、敌人出现），但 H5 3 秒后
  把按钮恢复成可用并提示「开始指令无响应」；线上 M3 构建同样复现。
- **根因**：`unityInstance.SendMessage` 在本构建中是**同步**的——`onStateChange(Playing)` 在
  `sendMessage()` 返回**前**就到达。旧 `startGame()` 先发指令、再 `setPage('Starting')` 并挂 3 秒兜底计时器，
  于是把刚到的 Playing 覆盖回 Starting，计时器到期再打回 Ready。诊断时间线：
  `72.9ms onStateChange(Playing) → 73.1ms clearTimeout → 74.2ms setTimeout(3000)`。
- **修复**：`web/js/app.js` 的 `startGame()` 改为「先设 Starting + 兜底计时器，再 SendMessage」；
  同步回调会清掉计时器并进入 Playing，发送失败再回滚 Ready。H5 版本串提到 `?v=0.1.0-m3.1`。
- **影响面**：`restartGame()` 不受影响（其兜底只在页面仍为 Result 时生效，已复验）。
- **部署**：修复已用 `bash scripts/deploy-netlify.sh` 推到线上（deploy `6ae4a9c7b9f43373ae9bd439`，2 个文件上传，11.5s），
  随后 Edge 线上复测通过。
- **注意**：`docs/遗留问题.md` 第 6 节的「M3 观察项（回调全丢失）」很可能是同类时序问题的另一次表现，
  本次未复现，保留原观察结论。

### 9.3 开始兜底 hotfix（同日，线上反馈后）

- 问题：改顺序只解决「同步回调被覆盖」，3 秒兜底本身太短，且超时会 `setPage('Ready')`——
  慢机器上可能把正在跑的游戏判成没开始。
- 改动（`web/js/app.js`）：
  - 兜底 `3000ms → 9000ms`（`START_RESPONSE_TIMEOUT_MS`）。
  - 超时**不再打回 Ready**，只提示「启动较慢，若已在游戏中请直接玩；未开始请刷新」；页面保持 `Starting`（开始按钮禁用）。
  - 正常开始不受影响：`onStateChange(Playing)` 仍会清掉兜底计时器。
- 部署：Netlify deploy `6ae4ac36c9e86e36865102c1`，静态资源版本串 `?v=0.1.0-m3.2`。
- 线上 URL 复验（走代理）：
  - 正常开始：按钮 0.6s 内隐藏，10 秒内无「无响应」，从未退回 Ready（`m3-hotfix-playing.png`）。
  - 模拟 StartGame 丢失（缩短兜底到 600ms + 吞掉 Playing 回调）：只出现新提示，按钮保持禁用（`m3-hotfix-timeout.png`）。
- 未做：`RequestState` 一次性查询（需要改 Unity 并重建）；如 M4「连续重开 10 次 / 5 分钟」复现回调丢失再加。

  选「前方敌人距离 + 离墙距离」最优方向，合成 `KeyboardEvent` 按键。固定方向循环在 20 只敌人下会死（首测 29.3s）。
