# 遗留问题（执行前先看）

> 每次开始新里程碑（M2/M3/…）前先读本文件；解决一条就删一条。

## 1. 输入后端已改为 Both（M1）

- `ProjectSettings/ProjectSettings.asset`：`activeInputHandler = 2`（Both）。
- 原因：模板默认只启用新 Input System，而规范 5.5 要求用内置 `Input`（`Input.GetAxisRaw`）。
- 影响：改动需要重启 Unity 编辑器才生效；新 Input System 仍可用。

## 2. `GameManager._autoStart` 必须在 M3 关闭

- 当前场景里为 `true`：Play 后自动进入 `Playing`（M1 自测方便）。
- 接 H5 桥接时应改为 `false`，由 `StartGame` / `RestartGame` 驱动，否则 H5 还没点开始游戏就已经在跑。

## 3. `Esc` 暂停是临时调试键（M1）

- `GameManager.Update` 里用 `Input.GetKeyDown(KeyCode.Escape)` 切换暂停。
- M2 做暂停面板 / M3 接 H5 的 `PauseGame` / `ResumeGame` 后，删除这个快捷键。

## 4. WebGL 构建产物不入库

- `.gitignore` 忽略了 `web/unity/`；构建后用菜单 `Survival/Build WebGL` 重新生成，不要手工拷贝旧产物。
- `build-info.json` 由 `BuildScript` 扫描生成，不要手改。

## 5. SceneSetup 的已知坑

- `EditorSceneManager.NewScene` 会卸载未被场景引用的资源（`GameConfig` 曾被判为未使用而变成空引用）。
- 现状：`NewScene` 之后重新 `LoadAssetAtPath` 再赋值，已在 `Assets/Editor/SceneSetup.cs` 注释说明；改 SceneSetup 时不要把这个重载删掉。

## 6. M1 未覆盖、留给后续的事项

- 键盘实体按键未做自动化模拟，移动手感需人工按 10 秒确认（编辑器、WebGL 各一次）。
- 击杀分接口 `ScoreService.AddKill()` 已实现，但 M1 没有击杀手段，暂无人调用。
- 占位美术（圆点 + 网格）在 M2 换成正式表现。
- HUD / 暂停面板 / 结算面板 / H5 桥接 / 触控 / 音效均未做，不要提前实现。
