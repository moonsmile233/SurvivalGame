# 遗留问题（执行前先看）

> 每次开始新里程碑（M2/M3/…）前先读本文件；解决一条就删一条。

## 1. 输入后端已改为 Both（M1）

- `ProjectSettings/ProjectSettings.asset`：`activeInputHandler = 2`（Both）。
- 原因：模板默认只启用新 Input System，而规范 5.5 要求用内置 `Input`（`Input.GetAxisRaw`）。
- 影响：改动需要重启 Unity 编辑器才生效；新 Input System 仍可用。

## 2. WebGL 构建产物不入库

- `.gitignore` 忽略了 `web/unity/`；构建后用菜单 `Survival/Build WebGL` 重新生成，不要手工拷贝旧产物。
- `build-info.json` 由 `BuildScript` 扫描生成，不要手改。

## 3. SceneSetup 的已知坑

- `EditorSceneManager.NewScene` 会卸载未被场景引用的资源（`GameConfig` 曾被判为未使用而变成空引用）。
- 现状：`NewScene` 之后重新 `LoadAssetAtPath` 再赋值（GameConfig / Sprite / TMP Font Asset 都要重取），已在 `Assets/Editor/SceneSetup.cs` 注释说明；改 SceneSetup 时不要把这个重载删掉。
- 现在 `BuildScript` 每次构建前都会调用 `SceneSetup.GenerateScene()`，场景永远由代码生成，不要手工在场景里改结构。

## 4. 编辑器失焦时 Play 循环会停（本机实测）

- Player Settings 的 **Run In Background = 关闭**（规范 11.1 要求），Unity 编辑器在窗口失焦时会把 Play 循环一起停掉：表现为 `Time.frameCount` 停在 1~2、`Time.time` 不涨、Console 里只剩 `[GameManager] state=Playing`。
- 自测时趁 Play 中执行一次 `Application.runInBackground = true`（只改运行期，不动 PlayerSettings）即可恢复；这不是代码 bug。
- 排查时先看这条，别误判成玩法卡死。

## 5. TMP 中文文案与字体图集

- 游戏内文案全部在 `Assets/Scripts/UI/UiStrings.cs`；字符集在 `Assets/Fonts/ui-chars.txt`。
- 字体资产 `Assets/Fonts/NotoSansSC-UI-SDF.asset` 由 `Assets/Editor/FontAssetBuilder.cs` **用脚本生成**（菜单 `Survival/Rebuild Font Asset`）：
  - `Survival/Setup Scene` 缺字体时自动生成
  - `Survival/Build WebGL` 构建前无条件重烤
- 新增文案时：改 `UiStrings`（或 `ui-chars.txt`）→ 构建即可。若新字不在 `NotoSansSC-UI-Subset.otf` 子集里，构建会直接报错并列出缺字，此时需要换完整字体（`NotoSansSC-Regular.otf`，OFL）重新裁子集。

## 6. 留给 M4 及以后的事项

- **触控、音效、正式美术、敌人行为增强**均未做，不要提前实现（M4 起，见 `docs/玩法增强.md`）。
- 击杀分接口 `ScoreService.AddKill()` 已实现，但仍没有击杀手段，`Kills` 恒为 0；结算面板因此不显示「击杀」行。
- 占位美术（圆点 + 网格）仍是 M1 的样子，正式美术未做。
- 胜利（`Won`）路径在 M3 仍未完整跑过一次自然 60 秒；M3 的浏览器实测是自然失败 + 编辑器反射胜利。
- `Assets/Fonts/NotoSansSC-UI-Subset-SDF.asset` 是切 TMP 时手工生成的一份遗留字体资产，代码已改用 `NotoSansSC-UI-SDF.asset`；确认无引用后应删除（还没删，见 M2 记录）。
- 无头/软件渲染的 Playwright 环境里 Unity 帧率极低（`Time.maximumDeltaTime = 0.1` 导致游戏时间约慢 10 倍），浏览器全程自测会偏慢；这是测试环境现象，不是玩法 bug。
