# M6 拥挤手感重做（交接，2026-11-01）

> 背景：用户 2026-11-01 否决了「唯一站位槽 + 站定钉住」的拥挤方案。第 1 步的压测/性能部分验收有效，
> **只重做敌人之间的互动（移动 + 分离）**，不要动计分/难度/协议/性能基线。
> 回滚点：bookmark `m6-crowd-v1`（`43306e88`，钉子版最后一版，含压测探针与全部证据）。

## 1. 用户原话（验收口径以这段为准）

> 敌人之间可以有那种挤过来挤过去的感觉，但是不能有那种明明离的很近还在发生碰撞的感觉；
> 如果挤过来挤过去会有小部分重叠，我认为是没问题的，只要不变成所有敌人都完全重叠就行。

拆成可执行的四条：

1. **要有互动**：围住玩家时能看到互相挤、让位、缓慢换位；不是一坨定格动画。
2. **允许少量重叠**：两只敌人的中心距可以小于精灵直径（1.0），压到约 0.7～0.75（≈25～30% 重叠）是正常的。
3. **不要"很近还在撞"**：视觉上已经贴住/轻度重叠时，不要再来一次明显的推开/弹开；推挤必须是连续的，不能是"跳一下"。
4. **不能完全重叠**：任何两只中心距不应长时间低于约 0.3；不允许出现"赶路的敌人直接穿过站定敌人"那种完全重合。

## 2. 上一版为什么被否（别重复）

| 现象 | 原因 |
|---|---|
| 队形一动不动，没有互动 | 站位槽唯一 + `IsNearStance(<1.0)` 后完全不参与分离、到位后本帧不移动 → 站定即钉子 |
| "明明很近还在碰撞" | 分离起点 = 0.9 × 间距 0.95 = **0.855**，而精灵直径是 **1.0**：视觉上已经贴住/重叠还在推，就是用户说的碰撞感 |
| 一瞬间完全重合 | 只要一方在站位区就跳过整对，赶路的敌人会直接穿过站定的人 |
| 推挤像"跳一下" | 20Hz 定量位置修正（单次最多 0.12），不是连续力 |

上一版为"0 u/s 抖动"这个可测指标服务，把敌群做成了刚体阵型；**这次的验收指标要反过来**：
允许持续小幅移动，禁止的是"弹开"和"完全重合"。

## 3. 建议方向（不是唯一解，重做时可调整）

**核心：回到软分离（steering），把分离当力而不是位置，允许重叠。**

```
separation = Σ (自己 - 邻居) / |自己 - 邻居| × (1 - d / R)     // 线性衰减，别用 1/d²
velocity   = seek 方向 × 追击权重 + separation × 分离权重
速度做指数平滑（或限制加速度），朝向不要每帧翻转
```

- 分离半径 `R ≈ 0.75`（允许 25% 重叠；小于 0.3 才算"几乎重合"，可以另做硬兜底）；
- 分离权重 0.5～0.8，只取最近 4～6 个邻居；
- 禁止分离把合成方向推到 seek 的明显反方向（否则会来回抖）；
- 30Hz 更新 + 位置插值，或 60Hz + 平滑，二选一，不要 20Hz 定量跳变。

**站位槽的处理**（二选一，建议 A）：
- A. **去掉硬站位**：敌人只 seek「玩家 + 攻击距离」，靠分离自然形成人群；允许后面的人贴在前人背后。
- B. **站位降级为软偏好**：目标点保留（分环可复用），但不再"到位即钉住"，分离可以把它推离；到位后仍参与分离。

**保留可复用的东西**：均匀网格邻域（cell 取 0.75～1.0）、`PerfProbe` 的 `motionUps/unsettledMax` 指标（阈值改成"有持续挤动"）、
20/30Hz 的更新降频思路、`EnemySpawner` 的槽位分配（若选 B）。

**禁止**：1/d²、每帧顺序两两修正、物理刚体碰撞、把"0 抖动"当唯一验收、站定即钉子。

## 4. 验收方法

- **桌面 40 只围住静止玩家，录 10 秒**：能看出持续挤动/换位；没有两只长时间中心距 < 0.3；没有突然弹开。
- **Pixel diff 不再要求 0**（上一版要求 0 是错的口径）；改为「帧间差异存在但幅度小、无跳变」。
- **玩家走进人群**：附近敌人被挤开/让位，不会穿模完全重合。
- **真机录屏**（Honor 90 Pro）：手感只认人工；Desktop 先调，再真机。
- 性能与 17 条回归沿用第 1 步基线（20/30/40 仍要 ≥30 FPS 真机、桌面 ≥60；E2E smoke + 60 秒胜利）。
