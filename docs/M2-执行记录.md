## 2. 方案变更：英文 legacy Text → 中文 TMP（2026-10-30 下午）

第一版按旧 ticket 用 `UnityEngine.UI.Text` + `LegacyRuntime.ttf` 做英文 UI，功能和验收都过了；
用户随后要求游戏内显示中文，按 ticket 第 0 节整体返工：

- 字体：内置 `NotoSansSC-UI-Subset.otf`（SIL OFL，61KB，含 UI 所需全部汉字 + ASCII）→ TMP SDF 图集
- 文案：全部集中在 `UI/UiStrings.cs`（生命 / 时间 / 分数 / 暂停 / 已暂停 / 继续 / 胜利 / 失败 / 得分 / 存活 / 击杀 / 胜利奖励 / 重新开始）
- 字号（1280×720 参考分辨率）：生命 24、时间 36 粗、分数 28 粗、暂停 24 粗；暂停标题 64；结算标题 72、得分 40、明细 28、按钮 28

### 字体图集改成脚本生成（不再手点 Font Asset Creator）

`Assets/Editor/FontAssetBuilder.cs`：

- 字符来源 = `Assets/Fonts/ui-chars.txt` ∪ `UiStrings.AllCharacters`
- 生成参数与 ticket 一致：Sampling 64 / Padding 8 / SDFAA / Static / 1024×1024
- 三个入口：菜单 `Survival/Rebuild Font Asset`；`Survival/Setup Scene` 缺资产时自动；`Survival/Build WebGL` 构建前无条件重烤
- 生成后逐个校验 `UiStrings.AllCharacters`，缺字直接 `LogError` 并列出字符（防 tofu）

结果：**121 字符，1024×1024 Alpha8，Static**，`TextMeshPro/Mobile/Distance Field` shader，无缺字。

## 3. Editor 自测（Play Mode）

> 本机 Player Settings 的 Run In Background 为关闭，编辑器失焦时 Play 循环会停
> （`Time.frameCount` 停在 1~2）。自测时在 Play 中执行一次 `Application.runInBackground = true`
> 即可继续，不写入项目设置。这条已记进 `docs/遗留问题.md`。

| 项目 | 操作 | 结果 |
|---|---|---|
| 自动开局 / HUD 初值 | Play | `生命 100/100`、`时间 00:60`、`分数 0`，血条满格（`m2-editor-playing.png`） |
| HP / 分数联动 | 被撞后观察 | 数字与血条同步（如 `生命 64/100`）；分数每满 1 秒 +10 |
| 暂停 | 点「暂停」 | `state=Paused`、`timeScale=0`、显示「已暂停」；**3 秒后 `elapsed=7.0748` 与敌人坐标完全不变**；「继续」后恢复计时（`m2-editor-paused.png`） |
| Esc | 代码检查 | `GameManager` 已无 Esc 处理，`grep Escape Assets/Scripts` 无结果 |
| 失败 | 被撞死 | 「失败 / 得分 140 / 存活 140」，**HUD 保留**、遮罩生效、不显示「击杀」行（`m2-editor-defeat.png`） |
| 胜利 | 反射调用 `GameManager.Win()`（见第 6 节说明） | 「胜利 / 得分 800」，明细 `存活 600` + `胜利奖励 200`，HUD `时间 00:00`、`分数 800`，`timeScale=0`（`m2-editor-victory.png`） |
| 重开 ×3 | 「重新开始」→ 再判负 → 再重开，共 3 轮 | 每轮 `state=Playing`、`score=0`、`hp=100`、两个面板均关、`timeScale=1`；无重复面板、分数不累加 |
| 连点重开 | Lost 后再点一次 | 状态守卫生效，只重置一次 |
| Console | 全流程 | **0 error、0 warning** |
| 受击反馈 | 采样 `SpriteRenderer.color/enabled` | 扣血瞬间 `color=(1,0.25,0.25)`；0.1s 后恢复白色并以 ~0.1s 间隔翻转 `enabled`（10Hz）；死亡/重开恢复白色 + 可见 |
