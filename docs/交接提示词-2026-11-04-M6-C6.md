## 3. 环境 / 已知坑（本次新增）

- **batchmode 构建在本工程不可用**：编辑器开着时 batchmode 会静默退出（exit 1，日志只有 21 行）。
  必须用 MCP 菜单 `Survival/Build WebGL`；构建期间 MCP 会 Timeout/断线（正常），看 `web/unity/build-info.json` 是否更新。
- **MCP `ping not answered` 常见原因**：Unity 弹了模态框（例如「scenes have been modified externally」），
  编辑器主线程被挡（CPU 不涨）。处理：把 Unity 窗口提到前台按 Enter 选 **Reload**（场景与仓库一致时安全）。
- **改资产后必须先 refresh 再构建**：`Configs/*.asset` 是文本，若只改文件不触发 AssetDatabase 刷新，
  构建会用内存里的旧值（C5 踩过：改了 `_enemyEmergencyDistance` 但构建没生效）。
  用 `refresh_unity(scope=all, compile=request)` 后再构建。
- **trial 水印**：`Editor.log` 显示 `Product: Unity Personal`，但 c5l 构建的截图仍出现 `trial version` 水印。
  C7 必须先让用户确认 `Help > Manage License` 干净授权，再重建；仍带水印就停。
- 构建会改 `Assets/Scenes/Game.unity` / `Assets/Fonts/NotoSansSC-UI-SDF.asset`；提交前
  `jj restore --from <parent> web/unity Assets/Scenes/Game.unity Assets/Fonts/NotoSansSC-UI-SDF.asset`。
