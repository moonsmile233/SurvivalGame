## 2. 自测记录（Unity Editor，Play Mode）

测试时临时设置 `Application.runInBackground = true`（Player Settings 的 Run In Background 仍为关闭，仅为让编辑器失焦时 play loop 继续跑，不写入项目设置）。

| 项目 | 操作 | 结果 |
|---|---|---|
| 自动开局 | Play | `state=Playing`，`elapsed` 正常累加 |
| 敌人生成 | 观察前 8 秒 | 5 只；间隔约 1.5s；最初都在视口外（`vp.y=-0.06` 等） |
| 追踪 | 观察 2s | 敌人与玩家距离持续缩小 |
| 掉血 / 无敌帧 | 接触后观察 | 9 次 `damage=12`，HP 88→76→…→0，约 1s 一次；1s 内无连续掉血 |
| 失败 | HP=0 | `state=Lost survived=16.7s score=160`，GameManager 日志输出；存档分 = 16s×10 |
| 暂停 | `PauseGame()` | `Time.timeScale=0`；1.5s 后 elapsed=8.87、HP=40、敌人坐标完全不变 |
| 恢复 | `ResumeGame()` | `timeScale=1`，继续计时 |
| 移动/边界（正向） | 输入组件注入 `Move=(1,0)` | x 到达约 10.42（视口半宽 10.82）后不再越界 |
| 移动/边界（修正后） | `Move=(1,1)` 冲到右上角 | `pos=(10.282,4.470)`，精灵最大 x=10.782 < 10.822、y=4.970 < 5.0，完全在视野内 |
| 胜利 | 存活满 60s | `state=Won elapsed=60.00 remaining=0.00 score=800 kills=0`；同屏敌人上限 20 生效 |
| 重开（Lost→） | `RestartGame()` | `state=Playing elapsed=0 score=0 hp=100/100 spawnerList=0 pos=(0,0) timeScale=1` |
| 重开（Won→） | `RestartGame()` | 同上；随后 3s 内重新刷出敌人 |
| Console | 全流程 | 0 error、0 warning（MCP 自身连接日志除外） |
| GC | 反射连续调用各 `Update`/`FixedUpdate` 1000 次，`GC.GetAllocatedBytesForCurrentThread` 差值 | GameManager.Update / PlayerInputController.Update / PlayerController.FixedUpdate / EnemyAI.Update / EnemySpawner.Update 均为 **0 B** |

> 说明：Editor 下 `ProfilerRecorder("GC Allocated In Frame")` 的平均值被编辑器自身开销主导（关闭全部玩法组件时基线约 13.6 KB/帧），因此改用反射直调 + `GC.GetAllocatedBytesForCurrentThread` 精确验证玩法帧内无托管分配。

## 4. 遗留问题 / 决策

1. **输入后端**：模板默认 `activeInputHandler=1`（仅新 Input System），M1 按规范用内置 `Input`，已改为 `2`（Both，经确认保留）。该改动需要重启编辑器才生效。
2. **自动开局**：`GameManager._autoStart = true` 便于 M1 在 Editor 自测；M3 接 H5 后应置 false，由 `StartGame` 驱动。
3. **暂停调试键**：M1 临时用 `Esc` 切换暂停（无面板）；M2 做暂停面板后移除，改由面板/H5 调用。
4. **SceneSetup 的资产卸载坑**：`EditorSceneManager.NewScene` 会卸载未被场景引用的 `GameConfig`；已在 `NewScene` 后重新 `LoadAssetAtPath`，代码内有注释。
5. **图标/美术**：目前是 SceneSetup 生成的占位圆点和网格，M2 再做表现层。
6. **击杀分**：`ScoreService.AddKill()` 已实现但 M1 无击杀手段，暂无人调用。

## 5. 浏览器补测（2026-10-30）

M1 当时只做了 Editor 自测，未在浏览器验证；本节补上，并修掉暴露的问题。

- `web/js/app.js` `onReady`：原来只把遮罩文案改成 "Unity Ready"，遮罩从不隐藏，正好盖住 canvas（看不到画面、点击被吞、canvas 拿不到焦点）。改为调用 `showOverlay(null)` 隐藏遮罩。
