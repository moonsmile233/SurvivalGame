# M4.7 — 触控摇杆可视化（浮动，仅手机）

> 文档版本：2026-10-31T19:40+08 · 作者：军师 · 改前必须从磁盘重读；上下文旧副本作废。
> 触发：2026-10-31 用户真机反馈，确认保留锚点相对拖动逻辑，只补视觉反馈。
> 定位：P1 体验增强，**不改操作逻辑、不改协议、不改玩法**；在 M5-3 最终构建前完成即可。

## 0. 目标

当前 `TouchInput` 是“按哪走哪”的隐形浮动摇杆，手感已通过真机；缺点是玩家看不见摇杆中心/最大半径，
不知道速度为什么变。本次只加**可视化**：

- 手指按下：在按下点显示半透明外圈 + 内圈摇杆头；
- 拖动：摇杆头跟随手指，夹在外圈内；
- 松手 / 换手指 / 离开 Playing：立即隐藏；
- **桌面鼠标拖动不显示**（保持现状）；
- 不改变 `PlayerController` 的速度、死区、maxRadius。

## 1. 必须遵守

- 不新增素材文件、不新增字体、不新增第三方包。
- 不改 `WebGLBridge` / 协议 / 状态机。
- `Image.raycastTarget = false`，不能挡住暂停按钮或其它 UI。
- 每帧无 GC：复用一个 Sprite、两个 Image，不每帧 `new` 颜色/字符串。
- 摇杆外观用代码生成的圆（`Texture2D` → `Sprite.Create`），一次生成后缓存；不写盘、不用 `System.IO`。
- 只读 `TouchInput` 的公开状态，不在 View 里重复计算输入。

## 2. 实现要点

### 2.1 `TouchInput` 暴露只读状态

```csharp
public bool TouchActive { get; private set; }   // 仅触摸；鼠标为 false
public int FingerId { get; private set; }        // 当前跟踪的手指，-1 表示无
public Vector2 AnchorScreen { get; private set; }// 屏幕像素
public Vector2 CurrentScreen { get; private set; }
public float MaxRadiusPixels { get; private set; }
```

- 每帧 `Update` 开头置 `TouchActive = false`；`UpdateTouch` 里跟踪到手指时置 true 并更新四个值；
- `ResetTouch` / 手指抬起 / 走鼠标分支时置 false；
- 不要在属性 getter 里做分配或查找。

### 2.2 新增 `UI/TouchJoystickView.cs`

- 挂在 HUD Canvas 下的一个空节点（`Joystick`），含两个 `Image`：
  - `Base`：外圈，颜色约 `(1,1,1,0.16)`，直径 = `2 × MaxRadiusPixels / canvas.scaleFactor`；
  - `Knob`：摇杆头，颜色约 `(1,1,1,0.65)`，直径 ≈ `0.36 × Base`。
- 位置：`RectTransformUtility.ScreenPointToLocalPointInRectangle(canvasRect, AnchorScreen, null, out local)`；
  Knob 偏移 = `(CurrentScreen - AnchorScreen)` 夹到 `MaxRadiusPixels`，再除以 `canvas.scaleFactor`。
- 显隐条件：`TouchActive && GameManager.State == Playing`；其它状态一律隐藏。
- 轻点暂停按钮时摇杆闪现的抑制：若 `EventSystem.current.IsPointerOverGameObject(FingerId)` 为 true，则不显示
  （摇杆自身 Image 必须 `raycastTarget=false`，否则会误判）。
- 排序：`Joystick` 节点放在 HUD 之前（`SetAsFirstSibling()`），保证在 HUD/暂停面板下层。
- 视觉可选：0.08 秒淡入淡出（`CanvasGroup.alpha`），不做也不影响验收。

### 2.3 `SceneSetup`

- 创建 `Joystick` 节点与两个 Image，`raycastTarget = false`；
- 添加 `TouchJoystickView`，注入 `TouchInput`、`GameManager`、`Canvas`/`RectTransform`；
- `TouchInput` 在玩家对象上；`CreateHud` 需要拿到它（建议把 `TouchInput` 作为参数传入，或用
  `FindFirstObjectByType<TouchInput>()` 并检查非空，不要静默 null）；
- 场景仍由 `SceneSetup` 一键生成，不手拖。

## 3. 验收

- 390×844 DPR2（CDP 真实触摸）：
  - 按下并拖动 → 截图能看到外圈与摇杆头，摇杆头朝拖动方向偏移；
  - 松手 → 摇杆消失；
  - 暂停 → 摇杆隐藏（即使手指仍按着）；
  - 页面 `scrollY` 仍为 0。
- 844×390 横屏：摇杆大小/位置正常，不溢出、不遮挡 HUD。
- 桌面 Chrome 鼠标拖动：**不出现**摇杆，操作与现在一致。
- 真机 Honor 90 Pro：拖动跟手；3-2-1 结束后手移回屏幕能马上拖动；摇杆不挡暂停按钮。
- console 0 error；`Update` 无每帧 GC（Unity Profiler 或执行记录说明）。
- 截图入 `docs/evidence/`：`m47-joystick-mobile.png`、`m47-joystick-landscape.png`。

## 4. 边界

- 不做固定摇杆、不做瞄准/攻击、不改 `maxRadius`/死区/速度。
- 不做摇杆皮肤/设置项；iOS/Android 同一套。
- 不阻塞 M5-1 国内托管；但要在 M5-3 最终构建前合并。
- 若真机反馈“外圈太大/太显眼”，只调颜色与 `0.36` 比例，不改输入逻辑。
