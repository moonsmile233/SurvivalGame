**前置**：M2 已完成（`64bf1070`），Editor + 浏览器表现层已验证。先读 `docs/遗留问题.md` 和 `docs/项目规范.md` 第 7、8、9 节。
**目标**：浏览器里完成一局闭环：输入昵称 → 开始 → 玩 → 结束 → H5 显示本次分数与历史最高分 → 刷新后最高分还在。

## 1. Unity 侧

### 1.1 协议（`docs/bridge-protocol.md` 同步更新）

H5 → Unity，`SendMessage('WebGLBridge', 方法名, 单 string 参数)`：

| 方法 | 参数 | 行为 |
|---|---|---|
| `StartGame` | JSON `{"nickname":"..."}` | Ready → Playing；昵称只存不用（不渲染） |
| `PauseGame` | `""` | Playing → Paused |
| `ResumeGame` | `""` | Paused → Playing |
| `RestartGame` | `""` | Won/Lost → Playing（全量重置） |
| `SetPausedByVisibility` | `"true"` / `"false"` | 标签页隐藏时自动暂停；恢复时只恢复"因隐藏而暂停"的那次 |

Unity → H5，`.jslib` 调 `window.SurvivalGameBridge.*`：

| 事件 | 载荷 | 时机 |
|---|---|---|
| `onReady` | `{"protocol":1}` | 首帧后一次 |
| `onStateChange` | `{"protocol":1,"state":"Playing"}` | 每次状态变化（可选，调试/H5 驱动） |
| `onGameOver` | 规范 7.4 的 schema | Won/Lost，每局仅一次 |

规则：

- `onGameOver` 用 `bool _reported` 守卫；`StartGame` / `RestartGame` 时清零。
- 昵称通过 `StartGame` 存进 `WebGLBridge`，只放进 `onGameOver` 的 JSON；**不传进任何 Unity UI**（中文字体约束）。
- 跨边界只用 `JsonUtility`，禁止字符串拼接。
- `.jslib` 里每个回调 `try/catch`；页面没注册 bridge 时只 `console.warn`，不能让 Unity 崩。
- Editor 下 DllImport 走 `Debug.Log` 模拟，保证 Editor 也能跑完整状态机。

### 1.2 代码改动

| 文件 | 改动 |
|---|---|
| `Bridge/WebGLBridge.cs` | 删除 Ping/Pong 测试接口；新增 `StartGame/PauseGame/ResumeGame/RestartGame/SetPausedByVisibility`；订阅 `GameManager.OnStateChanged`，发 `onStateChange` / `onGameOver`；保存昵称 |
| `Bridge/WebGLBridge.jslib` | `JsNotifyReady(json)`、`JsNotifyStateChange(json)`、`JsNotifyGameOver(json)`，全部 `UTF8ToString` + try/catch |
| `Core/GameBootstrap.cs` | `NotifyReady()` 改为发 `{"protocol":1}`；仍只发一次 |
| `Core/GameManager.cs` | `_autoStart` 关闭；新增 `public void SetAutoStart(bool)` 或直接序列化 false（编辑器自测用 MCP 调 `StartGame`）；`RestartGame` 起新局时通知 bridge 清 `_reported`（通过事件/桥接自身处理） |
| `Core/GameManager.cs` / `PlayerController.cs` | **Ready 状态禁止移动**：`PlayerController` 检查 `GameManager.State == Playing`，否则速度清零；SceneSetup 注入引用 |

### 1.3 状态与时序

```text
页面加载 → 注册 window.SurvivalGameBridge → 加载 Unity → onReady → Start 按钮可用
Start 按钮 → SendMessage StartGame({"nickname"}) → Playing
标签页隐藏 → SetPausedByVisibility("true") → Paused（若在 Playing）
标签页恢复 → SetPausedByVisibility("false") → 仅在"因隐藏暂停"时恢复
Won/Lost → onGameOver（一次）→ H5 结果面板
重开 → SendMessage RestartGame → Playing；_reported 清零
```

- 手动暂停后切标签页再回来：**不自动恢复**（只能由 Resume 按钮/继续按钮恢复）。
- `onReady` 之前 Start 按钮必须 disabled。

## 2. H5 侧（重写 M0 测试页）

### 2.1 页面结构

```text
header：标题 + 昵称输入（label/for，maxlength=16）
game：canvas（16:9）+ 加载遮罩/进度 + 错误卡片（重试）
controls：开始游戏 / 重新开始（状态驱动）
result：本次得分、历史最高分、是否新纪录、昵称
footer：版本号 · 构建时间
```

- 昵称：`textContent` 渲染，禁止 `innerHTML`；空 → 默认「玩家」；>16 截断；emoji/中文正常。
- 开始按钮：`onReady` 前 disabled；点击后立即禁用，防连点。
- 结果面板：`onGameOver` 才显示；重复事件做幂等守卫。
- 最高分：`survival.bestScore`；只有 `score > best` 才更新；相等不算新纪录。
- 上次昵称：`survival.nickname` 预填，可清空。
- localStorage 全部 try/catch；不可用时回退内存并提示「本次成绩无法保存」。
- 刷新页面：回到 Loading → Ready，最高分从 localStorage 读回。
- `file://` 打开：直接显示「请用本地服务器打开」，不尝试加载 Unity。
- Unity 加载失败：错误卡片 + 重试按钮；**遮罩必须有 pointer-events**（M1 已删掉全局 `pointer-events:none`）。

### 2.2 响应式与可访问性

- 主容器 `max-width: 960px`，16:9 游戏区，`100dvh` + `env(safe-area-inset-*)`。
- 按钮 ≥44×44，输入 `font-size:16px`。
- 所有控件用 `<button>/<label>`；`:focus-visible`；`aria-live="polite"` 播报结果。
- 手机竖屏布局不破版；触控玩不了是 M4 的事，但页面本身要正常。

### 2.3 桥接时序

- `window.SurvivalGameBridge` 必须在加载 `unity.loader.js` **之前**注册（现有 `bridge.js` 已这样做）。
- `createUnityInstance` 直接嵌入 canvas，不用 iframe。
- 发送前检查 `unityInstance && typeof SendMessage === 'function'`。
- 所有 Unity 事件参数是 JSON 字符串；H5 `JSON.parse` 失败只记日志，不崩页面。
- 不轮询 Unity 状态；HUD 数字在 Unity 内。

## 4. 验收清单

**闭环**
- [ ] 输入昵称 → 开始 → 能玩；H5 显示昵称，Unity UI 不出现昵称
- [ ] 死亡/胜利后 H5 显示本次得分与历史最高分，仅 `score > best` 更新
- [ ] 点「重新开始」→ Unity 全量重置，H5 结果面板关闭，分数不累加
- [ ] 刷新页面 → 最高分仍在；清空 localStorage → 0 且不报错

**时序与异常**
- [ ] `onReady` 前开始按钮禁用；连点只开一局
- [ ] 结算后连续重开 3 次：无重复 `onGameOver`、分数不累加、无敌计时不残留
- [ ] 标签页隐藏自动暂停；恢复只恢复自动暂停的那次；手动暂停不会被自动恢复

- [ ] localStorage 不可用 → 游戏可玩，页面提示不能保存
- [ ] `file://` 打开 → 明确提示用服务器，不白屏
- [ ] Unity 加载失败 → 错误卡片 + 重试可点

- [ ] 浏览器 console 0 error；H5 页面 console 0 error
- [ ] 桌面 Chrome / Edge 通过；手机 DevTools 布局正常（触控 M4）
