# M1 — 核心玩法（Editor 内可完整玩一局）

**前置**：M0 验收通过（场景能生成、WebGL 能构建、桥接能通）。
**目标**：在 Unity Editor 里完整跑通"移动 → 敌人追踪 → 掉血 → 死亡/胜利 → 重开"。
**不做**：正式 HUD、暂停面板、H5 桥接、最高分、触控、音效、美术打磨。

---

## 1. 场景静态结构（扩展 SceneSetup）

`Survival/Setup Scene` 生成/更新 `Assets/Scenes/Game.unity`，包含：

| 物体 | 组件 | 说明 |
|---|---|---|
| Main Camera | Camera | 正交，size 5，背景 `#1E1E2E` |
| Background | SpriteRenderer | 纯色/网格贴图，sortingOrder = -10 |
| Player | Rigidbody2D + CircleCollider2D + SpriteRenderer + PlayerController + PlayerHealth + PlayerInputController | 初始位置 (0,0) |
| EnemySpawner | EnemySpawner | 空物体 |
| GameManager | GameManager | 空物体 |
| WebGLBridge | WebGLBridge | M0 已有 |

**动态物体**：敌人实例由 `EnemySpawner` 运行时生成，**不要**在场景里预先摆放。

> 纪律：静态结构归场景，动态物体归代码。不要把敌人拖进场景。

## 2. 脚本清单

| 文件 | 职责 | 禁止 |
|---|---|---|
| `Core/GameConfig.cs` | ScriptableObject，所有数值 | 不写逻辑 |
| `Core/GameManager.cs` | 状态机、计时、胜负、重开 | 不处理输入/不写分数算法 |
| `Core/ScoreService.cs` | 存活分 + 击杀分 + 胜利奖励 | 不碰 UI |
| `Player/PlayerInputController.cs` | 键盘 → `Vector2 move` | 不直接移动 |
| `Player/PlayerController.cs` | 按输入移动、边界钳制 | 不改状态机 |
| `Player/PlayerHealth.cs` | HP、受伤、无敌帧、死亡事件 | 不直接调 UI |
| `Enemy/EnemySpawner.cs` | 定时生成、间隔递减、上限、清场 | 不追踪玩家 |
| `Enemy/EnemyAI.cs` | 追踪玩家、接触伤害 | 不判断胜负 |

**事件约定**（用 C# `event` / `Action`，不要用 SendMessage）：

```csharp
GameManager.OnStateChanged   // (GameState)
GameManager.OnTimeChanged    // (float remaining)
ScoreService.OnScoreChanged  // (int score)
PlayerHealth.OnHealthChanged // (int current, int max)
PlayerHealth.OnDied          // ()
```

## 4. 实现要点

### 移动
- `Rigidbody2D`：`gravityScale = 0`，`freezeRotation = true`，`collisionDetectionMode = Continuous`
- `PlayerController.FixedUpdate` 里 `rb.linearVelocity = input * speed`（Unity 6 用 `linearVelocity`，不是 `velocity`）
- 位置钳制在相机可视范围内（用 `Camera.main.ViewportToWorldPoint` 计算边界）

### 敌人
- 使用 `transform.position = Vector2.MoveTowards(...)` 或 `rb.linearVelocity`，二选一，保持简单
- `CircleCollider2D.isTrigger = true`
- 生成位置：相机视野外一圈（用视口坐标 ±0.15 的随机点）
- 接触判定：`OnTriggerStay2D` 里调用 `PlayerHealth.TakeDamage(damage)`
- 无敌帧由 `PlayerHealth` 内部处理，敌人不做冷却

### 计时与暂停
- `GameManager.Update` 用 `Time.deltaTime` 累加 `_elapsed`
- 暂停 = `Time.timeScale = 0`
- 所有玩法逻辑禁止用 `Time.unscaledDeltaTime`

### 状态机
```
Ready → Playing → (Won | Lost) → Playing (Restart)
Playing ↔ Paused
```
- `GameManager` 是唯一能改状态的类
- 重开 = 调用各系统 `Reset()`，**不要** `SceneManager.LoadScene`

### 重开必须清干净
- 敌人全部销毁/回收
- 玩家位置、HP、无敌计时归零
- 计时、分数、击杀数归零
- 生成计时重置
- `Time.timeScale = 1`

### 性能
- 敌人 ≤ 20，无需对象池；如果实现池化，只做最简单的栈式池，不要过度设计
- `Update` 里禁止 `GetComponent`、`Find`、LINQ、字符串拼接
- 每帧不产生新数组/列表分配

## 5. 验收清单

- [ ] Play 后玩家可用 WASD/方向键移动，四向平滑，不出界
- [ ] 敌人按 1.5s 间隔生成，位置在视野外
- [ ] 敌人持续追向玩家
- [ ] 敌人接触玩家 → 掉 12 血；1 秒内不会连续掉血
- [ ] HP 归零 → 状态 Lost，GameManager 日志输出
- [ ] 存活满 60 秒 → 状态 Won
- [ ] 重开后：敌人清空、HP 满、时间归零、分数归零、玩家回原点
- [ ] 暂停后所有物体静止，计时不变
- [ ] Console 无报错、无每帧警告
- [ ] Profiler 里 `Update` 无 GC 分配（稳定后）
