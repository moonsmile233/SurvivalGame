## 4. M5-2：真机门禁

顺序很重要——先排除设备问题，再判断托管问题：

1. **局域网确认设备侧**：手机与 PC 同一 Wi-Fi，打开 `http://<PC 局域网 IP>:8000`
   （PC 上 `cd web && python -m http.server 8000`；Windows 防火墙需允许 8000）。
   能秒开 → 设备/WebGL 正常，之前的失败是境外带宽；仍打不开 → 记下现象，先查设备/网络，不要继续换托管。
2. **国内链接真机**：Honor 90 Pro（Android Chrome）测：
   加载时间、触控跟手、HUD 可读、竖屏提示、横竖屏旋转、安全区、最高分、失败/重开、页面不滚动。
3. iPhone Safari 15+：有设备就测同样的项；**没有设备就明确写「无设备，未测」**，不要拿桌面 Safari 冒充。
4. 帧率：中端 Android 目测卡顿/用浏览器性能面板；<30 FPS 时先降 DPR（`bridge.js` 上限 2 → 1.5），
   这是唯一允许的 M5 性能改动，改完重新构建/部署/记录。
5. 证据：截图按 `m5-<device>-<state>.png` 放 `docs/evidence/`。
