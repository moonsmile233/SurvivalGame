## 1. 场景静态结构（扩展 `SceneSetup`）

新增：

| 物体 | 组件 | 说明 |
|---|---|---|
| HUD Canvas | Canvas(Screen Space - Overlay) + CanvasScaler(1280×720, Match 0.5) + GraphicRaycaster | HUD / 暂停面板 / 结算面板都挂这里 |
| EventSystem | EventSystem + **StandaloneInputModule** | 按钮点击必需；输入后端已是 Both（遗留问题 1） |

Canvas 下的层级（**全部由 `SceneSetup` 代码生成，禁止手工拖拽**）：

```text
HUD Canvas
├── HUD                     (常驻)
│   ├── HPBar (bg Image + fill Image)
│   ├── HPText       "HP 100/100"       左上
│   ├── TimeText     "TIME 00:60"       上中
│   ├── ScoreText    "SCORE 0"          右上偏左
│   └── PauseButton  "PAUSE"            右上
├── PausePanel              (默认 inactive)
│   ├── Dim (Image, rgba 0,0,0,0.6)
│   ├── Title "PAUSED"
│   └── ResumeButton "RESUME"
└── ResultPanel             (默认 inactive)
    ├── Dim
    ├── TitleText   "VICTORY" / "DEFEAT"
    ├── ScoreText   "SCORE 1234"
    ├── BreakdownText "SURVIVAL 600\nKILLS 0\nWIN BONUS 200"
    └── RestartButton "RESTART"
```

- 字体：`Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`，用 `UnityEngine.UI.Text`。
  **不要用 TMP**（本项目不需要，字体资产会多一层坑）。
- 文案只用英文 + 数字（硬约束 4）；中文留给 H5。
- 按钮最小点击区 48×48；文字 16px 起。
- PauseButton 只在 `Playing` 可见；`Paused/Won/Lost` 隐藏（面板会盖住它，但状态语义要正确）。

## 3. 规则与细节

### 显示
- 剩余时间：`ceil(60 - elapsed)`，格式固定 `00:60` ~ `00:00`（规范 6.1 的格式，不要自作主张改成 `01:00`）。
- HP：数字 `HP 100/100` + 血条（fill Image，`fillAmount = current/max`，类型 Filled/Horizontal）。
- 分数：存活每秒 +10，随 `OnScoreChanged` 刷新。
- 结算明细：`SURVIVAL = 存活秒×10`、`KILLS = 击杀×20`、`WIN BONUS = 200`（仅胜利）。

### 冻结
- `Paused`：`Time.timeScale = 0`（已有）。
- `Won` / `Lost`：**新增** `Time.timeScale = 0`，让敌人、玩家、生成器全部停住；面板按钮用 uGUI，不受 timeScale 影响。
- `RestartGame` / `StartGame`：`ResetRound` 里先恢复 `timeScale = 1`（已有）。
- 玩法逻辑仍然一律 `Time.deltaTime`，禁止用 `unscaledDeltaTime` 做计时。

### 状态与面板
- `Playing`：HUD 开、PauseButton 开、两个面板关。
- `Paused`：PausePanel 开，HUD 保留（底层显示）。
- `Won/Lost`：ResultPanel 开，HUD 保留。
- 状态切换只由 `OnStateChanged` 驱动，面板里不缓存"我猜的状态"。
- `RestartGame` 后必须看不到上一局的任何面板；连点 Restart 只生效一次（状态从 Playing 起就不再接受 Restart，现有守卫已满足）。

### 受击反馈（M2 必做，不是美术打磨）
- 真正扣血时：`SpriteRenderer.color` 变红 0.10s，随后按 `InvincibleDuration`（1s）以 10Hz 切换 `SpriteRenderer.enabled`，结束后恢复白色 + enabled。
- 用 `PlayerView.Update` 的计时器实现，**不要用协程/材质实例**；计时用 `Time.deltaTime`，暂停时自然冻结。
- 死亡 / 重开时必须恢复 `color = Color.white`、`enabled = true`，不能残留半透明或红屏。
- 反馈只读事件，不反向调用 `PlayerHealth`。

### 结算与击杀分
- 当前没有击杀手段，`Kills` 恒为 0。结算面板在 `Kills == 0` 时**不显示 KILLS 行**（避免出现"KILLS 0"这种半成品感）；`ScoreService.Kills` 与协议字段保留给 M3/后续。
- `ScoreService` 增加 `SurvivalScore` / `KillScore` / `WinBonus` 只读属性供结算明细；`onGameOver` 的 breakdown 字段在 M3 再接。

### 性能
- 时间文本每秒才变：HUD 缓存上一次的整秒数，整数不变就不重建 string。
- 分数/HP 只在事件回调里重建字符串；**`Update` 里禁止字符串拼接**。
- `Update` 里禁止 `GetComponent` / `Find` / LINQ / 每帧 new。

### 输入
- 删除 `GameManager.Update` 里的 Esc 逻辑（遗留问题 3）。
- 暂停只由 PauseButton /（M3 起）H5 的 `PauseGame` 触发。
