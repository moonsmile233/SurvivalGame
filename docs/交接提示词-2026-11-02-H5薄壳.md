- `web/js/app.js`：壳状态机 `Loading → Shell → Entered → GameOver`（`Error` 兜底）：
  - `onReady` 必须 `protocol===3`，否则禁用开始 + 错误卡；迟到的 onReady 不改写 Error；**事件早于 onReady 时直接进 Entered**（perf autostart 乱序守卫）；

  - `onStateChange` 只更新文案，不控制布局；`onGameOver/onDifficultyChanged` 校验 protocol=3，Error 状态忽略事件；
  - 单一最高分 `survival.bestScore` + `bestScoreMigrated` 迁移（旧三档取 max，只读一次）；最近一局只在内存；
  - 全屏入口只在 Entered 后出现；失焦只发 `SetPausedByVisibility`；不发局内指令；`?testhook=1` 暴露状态/已发消息。
- `web/js/bridge.js`：转发 `onDifficultyChanged`；其余加载逻辑不变。
