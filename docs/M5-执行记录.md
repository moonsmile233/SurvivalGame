## M5-1：国内托管（待用户操作）

CloudBase 需要账号与实名，**执行方不代注册**。用户需要做：

1. 登录腾讯云 → 云开发 CloudBase → 新建环境（按量计费/免费额度即可）。
2. 环境里开启 **静态网站托管**，拿到默认域名。
3. 把 `D:\unityFile\SurvivalGame\web\` 全量上传（index.html、css/、js/、unity/）。
4. 配置缓存：`index.html`、`build-info.json` 不缓存；`unity/Build/*` 文件名固定，部署后清 CDN 缓存。
5. 完成后把「环境 ID / 默认域名」发给执行方；手机**关 Wi-Fi、关代理、4G 直连**打开，记录到开始按钮的秒数。

> 备选：阿里云 OSS 默认域名（确认 `text/html` MIME）→ 香港轻量云。Gitee Pages 已停服，不要试。
