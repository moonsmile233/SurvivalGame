> 2026-10-31 记录。目标：面试官拿到链接或压缩包，能用最短路径玩到游戏。

## 1. 硬约束：WebGL 不能双击 `file://` 打开

- Unity WebGL 通过 `fetch` 加载 `build-info.json`、`.data/.wasm/.framework`，浏览器在 `file://` 下按跨域拦截，
   `createUnityInstance` 起不来。这不是我们的 bug，Chrome / Edge / Firefox / Safari 都一样。
- 当前 H5 已显式检测 `location.protocol === 'file:'` 并提示"请用本地服务器打开"（`web/js/bridge.js`）。
- 结论：**不部署也能玩，但必须通过 HTTP 服务打开**。双击 `index.html` 不行。
- 作业只要求"源码、WebGL 构建文件和 README"；README 写清 `python -m http.server` 即可满足。
  但面试场景下，让面试官开终端起服务是额外门槛，**部署一个链接仍然是最优解**。

### 本地压缩包（备用，不作为主入口）

`web/` 目录 + 一个启动脚本即可：

- `start-local.bat`（Windows）：优先用 `python -m http.server 8000`，失败再试 `py` / `node`，然后打开浏览器。
- `start-local.sh`（macOS/Linux）：同上。
- 局限：面试官机器不一定装了 Python/Node；脚本被杀软拦截也麻烦。**压缩包只作为源码/构建备份**。

不建议为了"单文件双击可玩"去做 base64 内联或 Electron 壳：体积、内存、跨域、维护成本都不划算。

## 1.5 手机“全屏 / APK / PWA”怎么选（2026-10-31）

### 全屏不是可玩性的前提

- 手机浏览器里**不进全屏也能玩**：页面里的 canvas 已 `touch-action:none`，触控全屏拖动；
  只是浏览器地址栏会占掉一部分高度，游戏区变小。
- 全屏（M4.5 §1，**必做**）是体验项：隐藏浏览器 chrome、游戏区更大；iOS Safari 支持有限，需要降级提示。
- 真机已证明（Honor 90 Pro 局域网）无全屏功能上能玩；但用户明确体验很差，所以全屏按必做排期，
  不要把它说成“不做也能接受”。

### 如果确实要一个“手机软件”

| 方案 | 做法 | 优点 | 风险/成本 | 建议 |
|---|---|---|---|---|
| **WebView / Capacitor / TWA 包装 H5** | 把 `web/` 放进 Android 壳，WebView 加载本地或线上页面 | 快，能生成 APK/桌面图标 | Unity WebGL 在 Android WebView 的 WebGL2/内存/性能不稳定；要处理本地资源 CORS、横屏、全屏、返回键 | 只适合“要个 App 图标”，不能替代浏览器验收 |
| **Unity 直接构建 Android APK** | 切 Android 平台，IL2CPP + ARM，签名 | 性能最稳，真正的原生 App | 需要 Android Build Support/签名；H5 的昵称/开始/最高分要改成 Unity 或原生 UI，等于另一个交付物 | 作业不要求，本次不做 |
| **PWA（添加到主屏幕）** | manifest + service worker + HTTPS | 接近全屏、无需 APK | 需要 HTTPS/托管；iOS 限制多；缓存策略要处理 | 可选增强，不如先做 H5 全屏 |
| **Electron/桌面壳** | 包装 web/ | 双击可玩 | 体积大、跨域/内存问题 | 不建议 |

### 本次结论

- 作业要求是 **H5 页面 + Unity WebGL + 源码/构建/README**；APK 不是必需，也不能替代这些交付物。
- **H5 全屏是必做**（用户 2026-10-31 明确：手机浏览器不全屏时体验很差）；顺序在 M4.7 后、最终构建前，半天盒。
  桌面/Android Chrome 真全屏；iPhone Safari 支持有限，必须做失败降级提示。
- PWA 属于可选，放在全屏之后。
- 如果面试方明确要“手机 App”，再单独立项做 **Unity Android 原生构建**；不要用 WebView 壳硬凑，
  也不要为了 APK 把交付时间挤掉 M5。

## 2. 国内托管选项（2026-10）

> 信息来自公开搜索，**未走代理实测**；具体额度/备案要求以各平台控制台为准。

| 方案 | 免备案 | 适合度 | 备注 |
|---|---|---|---|
| **腾讯云 CloudBase 静态托管** | ✅ 默认域名 `*.tcloudbaseapp.com`（公开资料称已备案） | **首选先试** | 免费 5GB 存储 + 5GB CDN/月；9.4MB/次约 530 次加载，面试够用 |
| 阿里云 OSS 静态托管 | ✅ 默认域名 | 备选 | 按量付费很便宜；先确认默认域名能直接以 `text/html` 打开 |
| 腾讯云 EdgeOne Pages（2026.6 起 EdgeOne Makers） | ⚠️ | 有备案域名时最佳 | 免费额度大（不限流量），但大陆默认域名只给 3 小时预览链接；稳定大陆访问需绑**已备案**域名 |
| 香港轻量云 + Nginx | ✅ | 可控备选 | 腾讯云/阿里云香港，IP 直连或未备案域名；约 ¥30/月，多一层运维 |
| Gitee Pages / CODING Pages | — | **不可用** | Gitee Pages 已于 2024 年停止服务，旧教程会踩坑 |
| GitHub Pages / Netlify / Vercel / Cloudflare Pages | ✅ | 海外备份 | 国内经常慢或打不开；**不要把 Netlify 作为主链接** |

### 推荐路径

1. **CloudBase** 部署一版，手机 4G（关 WiFi、不走代理）打开，测"到开始按钮可用"的秒数；目标 <15 秒。
2. 不行再试阿里云 OSS 默认域名（先确认 HTML MIME）。
3. 有备案域名 → EdgeOne Pages / COS+CDN；没有就别为它等备案。
4. Netlify 只留作海外备份。

### 部署检查单

- [ ] **构建画面右下角没有 `trial version` 水印**（Unity 许可证有效；水印包不得发布）
- [ ] `web/unity/build-info.json` 指向真实产物（`BuildScript` 生成，不手改）
- [ ] `/unity/Build/*` 与 `build-info.json` 设 no-cache，或每次部署后清 CDN；否则浏览器跑旧包
- [ ] H5 的 `js/css` 带 `?v=` 版本串，每次发布递增
- [ ] 手机 4G 直连实测加载时间（**不要用 Clash 代理数字**）
- [ ] 微信内打开一次（如果会发到微信）
- [ ] 记录包体、构建时间、首屏时间到执行记录

### 配额估算

- 当前约 9.4MB/次完整加载；CloudBase 5GB CDN/月 ≈ 530 次。面试官多次刷新/多人访问可能吃紧，
  超出后按量付费；如果要把链接长期放简历，建议直接上 OSS/COS 按量付费（几元/GB）。
- 体积优化（M5）：stripping、关闭 Decompression Fallback + 服务器 `Content-Encoding: br`、CDN 缓存；
  改构建参数前先实测，不要凭感觉。
